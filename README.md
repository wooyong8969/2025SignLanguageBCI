# 수어 상상 기반 뇌-컴퓨터 인터페이스 탐구

> 기간: 2025년 3월 ~ 2025년 9월(-ing)  
> 형태: 전국과학전람회 탐구 프로젝트  
> 주제: 말과 동작을 동시에 상상하다! — 새로운 차세대 뇌-컴퓨터 인터페이스 탐구

---

## 🧠 개요

저희는 **수어 상상(Sign Language Imagery)**이 기존 BCI 시스템의 입력체계보다
더 유리한 조건을 가질 것이라는 가정하에 새로운 뇌-컴퓨터 인터페이스(BCI) 입력 방식을 세계 최초로 제안하고,  
기존의 **발화 상상(Speech Imagery)** 및 **동작 상상(Motor Imagery)**과 동일 조건에서 직접 비교했습니다.  

그 결과, 수어 상상이 발화 상상과 동작 상상의 특징을 모두 지니며, +@의 특징 역시 지님을 확인했습니다.  
또한, 수어 상상이 발화 상상보다 통계적으로 유의미하게 **더 높은 인식률**을 보임을 과학적으로 검증했습니다.  

즉, 저희 탐구는 ‘수어 상상이 뇌파 인식에서 실제로 더 잘 작동할 수 있다’는 사실을 처음으로 보여준 **Proof of Concept**입니다.

---

## 🔎 탐구 동기

- **발화 상상 BCI**: 언어적 의미를 담지만, 신호가 약해 잡음에 묻힘 → 인식률 낮음  
- **동작 상상 BCI**: 신호가 강하지만, 언어적 의미를 담지 못함 → 의사소통 한계  
- **수어 상상 BCI**: 말과 동작을 동시에 상상 →  
  1) 발화+동작의 장점을 결합  
  2) 새로운 고유 신호 가능성  

따라서 저희는 다음 두 가설을 세웠습니다.  
1. 수어 상상은 발화+동작 상상의 특징을 모두 지닌다.  
2. 수어 상상은 발화 상상보다 인식률이 높다.

## ⚙️ 탐구 과정

1. **데이터 수집**  
   - OpenBCI 16채널 장비 사용  
   - 동일 단어 4개 × 3가지 상상 방식 × 30회씩 EEG 기록  

2. **전처리**  
   - 주파수 대역 필터링 (1–50Hz)  
   - EOG/EMG 잡음 제거  
   - 평균 재참조  

3. **신경생리학적 분석**  
   - 스펙트로그램(시간-주파수 분석)  
   - sLORETA(공간 활성 분석)  
   - PLV(기능적 연결성)  

4. **머신러닝 분류**  
   - CSP 기반 특징 추출  
   - LDA 분류기, EEGNet 비교  
   - 100회 반복 실험 → 평균 정확도 산출  

---

## 📊 주요 결과

- **가설 1 검증**:  
  - 수어 상상은 발화·동작 영역 모두 활성화 + 새로운 영역까지 활성화 → +@ 특징 확인  

- **가설 2 검증**:  
  - 평균 인식 정확도 (4-class, CSP+LDA 기준)  
    - 발화 상상: **40.0%**  
    - 동작 상상: **43.2%**  
    - 수어 상상: **48.5%**  
  - → 발화 대비 수어에서 **통계적으로 유의미한 상승** 확인

## 🌍 탐구 의의

1. **세계 최초**: 수어 상상을 BCI 입력으로 검증한 첫 시도  
2. **Proof of Concept**: 단순 아이디어 제시가 아니라 실제 데이터와 분석으로 가능성 입증  
3. **직접 구현**: 상용 프로그램이 아닌, 전처리·특징 추출·분류·시각화까지 Python으로 직접 코드 작성  
4. **보편성**: 발화가 어려운 사람, 수어 사용자, 미래의 메타버스/VR 소통까지 확장 가능한 입력 수단
